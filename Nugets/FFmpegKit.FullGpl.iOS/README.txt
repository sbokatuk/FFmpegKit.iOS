## FFmpegKit.FullGpl.iOS

Thank you for installing FFmpegKit.FullGpl.iOS, for details and issues reporting use our sources repository:
https://github.com/sbokatuk/FFmpegKit.iOS

This is a .NET (net8.0-ios) binding for the native FFmpegKit library (https://github.com/ffmpegkit-maintained/ffmpeg-kit-ios-full), FullGpl flavor.

Note: this build includes GPL-licensed codecs (e.g. libx264). Any application distributing it must comply with the GPL.
