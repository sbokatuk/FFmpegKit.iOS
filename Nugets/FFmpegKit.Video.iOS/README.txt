## FFmpegKit.Video.iOS

Thank you for installing FFmpegKit.Video.iOS, for details and issues reporting use our sources repository:
https://github.com/sbokatuk/FFmpegKit.iOS

This is a .NET (net8.0-ios) binding for the native FFmpegKit library (https://github.com/arthenica/ffmpeg-kit), Video (non-GPL) flavor.

Note: this package is currently a placeholder — no non-GPL xcframework has been built into it yet. See the FullGpl.iOS package/README for the actively maintained, built flavor.
